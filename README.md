# Persistent Memory AI Customer Assistant

This Python script demonstrates how an AI customer support assistant can maintain persistent memory across interactions. It simulates storing a customer's name and their last reported issue in a JSON file, allowing the assistant to recall this information in subsequent sessions for a personalized experience.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`.
3. Follow the prompts and observe how the assistant remembers details across simulated sessions. You can also run the script multiple times to see persistence across actual program executions.
